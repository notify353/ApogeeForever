# Apogee for WoW Forever

Includes Heals, Keybinds, Dungeons, Essentials and Stats for Forever 1.60.1.
Keep the top-level Apogee addon enabled and choose the components you want.
Restart after first installation; reload after changing enabled components.

Left-click the green minimap button to toggle the healing and keybind editors.
Right-click for settings or Reset UI positions; right-drag to move it. Reset UI
positions preserves settings and bindings.

Essentials enables instant quest text and sets A to Strafe Left and D to Strafe
Right at login or UI reload. Other keys are unchanged. Later native changes last
for the session; the next login or reload reapplies these defaults.

Stats offers role-based gear and loot guidance, character-window controls and
auction filtering. Buying remains manual. Guidance does not simulate every proc,
use effect, set bonus or stat cap.

This early release has automated and matching-client API checks. Live gameplay
testing is limited; it has not completed full native acceptance.

This is the public PROD package. DEV settings remain separate and are not imported.
Enable one complete family only; do not mix PROD and DEV components. The login
defaults above do not clear saved addon settings or custom spell assignments.
Install through CurseForge for the Forever game instance, or extract all six
folders into that instance's Interface/AddOns directory.
