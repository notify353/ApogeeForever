# Apogee for Classic Era

Includes Heals, Keybinds, Dungeons, Essentials and Stats for Classic Era 1.15.9.
Keep the top-level Apogee Era addon enabled and choose the components you want.
Restart WoW after first installation; reload after changing enabled components.

Left-click the green minimap button to toggle the healing and keybind editors.
Right-click for component settings or Reset UI positions; right-drag to move it.
Reset UI positions preserves settings and bindings.

Stats provides gear and loot guidance plus a character-window role control.
Its auction dice filters the current page for upgrades by role. Use the normal
Search and Next/Previous buttons. Buying remains a separate manual action.
Era stat reading supports English tooltips. Guidance does not simulate procs,
use effects, set bonuses or stat caps. Uncertain comparisons are omitted.
The Heals Follow/Inspect/Talents strip is not available on Era.

This is the public PROD package. DEV settings are separate and are not imported.
Enable one complete family only; do not mix PROD and DEV components. No settings,
bindings or addon enable preferences are reset or migrated by this release.
Install through CurseForge for the Classic Era game instance. Manual installs
extract all six folders into that instance's Interface/AddOns directory.
