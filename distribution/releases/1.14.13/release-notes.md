# Apogee Forever 1.14.13

- Quest text now appears immediately when Essentials is enabled.
- Essentials sets A to Strafe Left and D to Strafe Right at login or UI reload. Other keys are unchanged. Changes made later in the session remain until the next login or reload.
- Keybinds no longer refuses to start because the Apogee master is labeled legacy or unverified. Compatible features remain available across client and package version changes.
- Target actions remain available independently when another action is unavailable. Each action still checks its own requirements and range.

For WoW Forever 1.60.1. Enable the top-level Apogee addon and the components you want. When switching from DEV, disable the DEV family, enable the public family, and reload; their settings remain separate.

This early release has automated source and package checks against the reviewed Forever client API. Separate native acceptance of this update in Forever has not been recorded; full live gameplay and CurseForge-client testing remain incomplete.
