# Apogee Classic Era 1.14.12

- Quest text now appears immediately when Essentials is enabled.
- Essentials sets A to Strafe Left and D to Strafe Right at login or UI reload. Other keys are unchanged. Changes made later in the session remain until the next login or reload.
- Keybinds no longer refuses to start because the Apogee master is labeled legacy or unverified. Compatible features remain available across client and package version changes.
- Follow and Inspect remain available when talent inspection is unavailable. Each action still checks its own requirements and range.

For Classic Era 1.15.9. Enable the top-level Apogee Era addon and the components you want. When switching from DEV, disable the DEV family, enable the public family, and reload; their settings remain separate.

Automated source and package checks cover both families. The owner reported the updated DEV build working in Era. This does not claim a separate test of the public CurseForge package.
