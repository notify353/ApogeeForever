# Apogee Forever 1.14.14

- Compatibility review for the WoW Forever launch client 1.60.1, build 70790.
- Retains the existing healing, keybind, dungeon, convenience and gear features, including instant quest text and A/D strafing.
- Incoming damage percentages show `--` when the client restricts damage amounts; Apogee does not calculate with restricted values.

For WoW Forever 1.60.1. Enable the top-level Apogee addon and the components you want. When switching from DEV, disable the DEV family, enable the public family, and reload; their settings remain separate.

This release uses a fresh client API export and automated source/package checks. In-game testing was skipped for this launch update; native gameplay, timing/taint and CurseForge-client acceptance are not claimed.
