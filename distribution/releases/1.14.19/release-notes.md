# Apogee Forever 1.14.19

- Added raid-marker defaults: Middle Click for Skull, Shift + Middle Click for Cross, and Ctrl + Middle Click for Moon, consistently across stances and forms.
- Marker defaults appear only when Enable default spells is on. Your own spell, item or macro replaces the default; clearing the assignment restores it.
- Marker icons and tooltips appear only during Apogee keybind editing. The shortcuts remain active during normal play and combat.
- Game sound now mutes while you have a focus and restores the prior sound setting when focus clears, including reload and logout recovery. A previously muted game stays muted.
- Updated client-build recognition for the reviewed Forever client.

Includes the existing resurrection, Druid combat Rebirth, healing-range, and other improvements from earlier releases.

For World of Warcraft Forever 1.60.1. Automated source and generated-package checks cover these changes; complete live-client acceptance is still pending.
