# Apogee Classic Era 1.14.10

First public Classic Era package, including Heals, Keybinds, Dungeons, Essentials and Stats.

- One green minimap button: left-click toggles healing/keybind editors; right-click opens component settings and Reset UI positions.
- Reset UI positions preserves settings and bindings.
- Healing defaults use the class starting heal or a bandage; your assignments take priority.
- Stats adds gear/loot guidance, character-window role controls, and auction upgrades by role on the current page. Searching, paging and purchases remain manual.

Supports Classic Era 1.15.9. Era stat reading currently requires English tooltips. Gear guidance does not simulate procs, use effects, set bonuses or stat caps. The Heals Follow/Inspect/Talents strip is unavailable on Era.

Existing Era DEV behavior has owner-reported in-game testing. This public PROD package has generated regression coverage; a separate CurseForge-client installation has not yet been tested.

Restart WoW after installation. Keep the Apogee Era master enabled, select your components, and enable only one complete PROD or DEV family. DEV settings are separate; this release does not import or reset settings/bindings. Report issues with the client version and error details.
