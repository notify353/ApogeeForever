# Apogee Forever 1.14.11

Updates the public Forever package to the current shared Apogee components: Heals, Keybinds, Dungeons, Essentials and Stats.

- One green minimap button opens the healing/keybind editors together, with component settings and Reset UI positions on right-click.
- Reset UI positions preserves settings and bindings.
- Includes the current healing defaults and bandage fixes, combat-only explosive bindings, error suppression improvements, and startup/cleanup hardening.
- Retains Forever's own gear guidance, character controls and auction implementation.

Supports Forever 1.60.1; API review matches live build 1.60.1.70685. Automated package and gameplay regressions pass, but live gameplay testing is limited and full native acceptance is pending. This is an owner-approved early Release; issues may remain on day one.

Restart WoW after installation. Keep the master addon enabled, choose your components, and enable one complete PROD or DEV family. Existing DEV settings remain separate and are not imported. No settings/binding reset is included. Report issues with the client version and error details.
